# SNU-KDT-KTalpha

KDT 캡스톤 KT알파 기업 과제 팀입니다.

## 과제

**홈쇼핑 방송 편성 최적화를 위한 외부 변수 영향도 분석 PoC**

날씨, 휴일, 타사 편성 같은 회사 밖 요인이 T커머스(KT알파 쇼핑) 방송 실적과 관련이 있는지, 그리고 예측 모델에 넣었을 때 예측이 실제로 좋아지는지 검증합니다.

## 하려는 것

- 외부 데이터(날씨, 공휴일, 검색 추이)를 수집해 방송 실적 데이터와 연결
- 자사 데이터만 쓴 예측과 외부 변수를 더한 예측을 비교해 영향도 검증
- 편성 담당자가 결과를 조회하는 웹 시제품 제작
